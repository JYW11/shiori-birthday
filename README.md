# しおりちゃんの22歳の誕生日ページ

## 起動方法
1. ZIPを展開します。
2. `shiori_birthday_site` フォルダを Visual Studio Code で開きます。
3. VS Code の Live Server 拡張機能を使い、`index.html` を `Open with Live Server` で開きます。
   - Live Server がない場合は、拡張機能タブで「Live Server」を検索してインストールしてください。
4. スマートフォンで確認する場合は、PCと同じWi-Fiに接続し、Live Server のネットワークアクセス可能なアドレスを開きます。

## 写真の入れ方
`assets/photos/` に写真を13枚入れ、次の名前にしてください。
- `photo-01.jpg`
- `photo-02.jpg`
- ...
- `photo-13.jpg`

PNGを使う場合も同じ番号で `.png` にすれば読み込めます。写真は縦横どちらでも表示できますが、縦長（4:5程度）がおすすめです。

## 音楽
送ってもらった音源を `assets/birthday-song.mp3` として同梱しています。
スマートフォンやブラウザの自動再生制限により、音楽は最初の画面を一度タッチした時点で再生を開始します。最初のタッチではイントロの灯りも点灯し、スライドはまだ進みません。

## 操作の流れ
- イントロ：最初のタッチで音楽とキャンドルの演出が始まります。もう一度タッチすると次へ。
- お祝いメッセージ：タッチでメッセージが表示され、もう一度で写真へ。
- 写真：タッチするたびに写真が中央に1枚現れ、次のタッチでランダム配置に固定されます。13枚を表示後、最後のメッセージが出ます。
- 편지：タッチごとに一文ずつ表示され、最後に署名が現れます。
- 마지막 화면：タッチ案内は表示されず、メッセージで終了します。

## 文字や演出の変更
- 表示文言：`index.html`
- 写真・手紙の進行：`script.js`
- 色・文字サイズ・アニメーション：`style.css`
